# Snap Quest

Настільна пригода: гравці викладають світ із паперових тайлів, фотографують дошку телефоном,
кажуть AI-ведучому, яку історію хочуть, і грають, кидаючи справжній d20.

## Як це працює

1. **Скан** — телефон фотографує дошку, сервер знаходить маркери на тайлах і збирає мапу
   (який тайл, де стоїть, як повернутий).
2. **Історія** — гравець пише, яку історію хоче, і додає героїв. Claude створює назву кампанії,
   місця на конкретних тайлах, стартову сцену й перший квест.
3. **Гра** — гравці пишуть дії або тиснуть варіанти; коли дія ризикована, ведучий просить кинути
   справжній d20 (є кнопка «кинь за мене»). Квести завершуються, з'являються нові.
4. **Перескан** — додали тайли на стіл? Скан → ведучий вплітає нову землю в історію.

Кампанії зберігаються на телефоні гравця (localStorage); сервер нічого не зберігає.

## Структура

| Шлях | Що це |
|---|---|
| `server/main.py` | FastAPI: `/api/scan`, `/api/story/start`, `/api/story/turn`, ліміти запитів, роздача застосунку |
| `server/scanner.py` | розпізнавання маркерів ArUco і збирання гексової мапи |
| `server/gm.py` | AI-ведучий (Claude, structured outputs) |
| `server/tileset.py` | типи місцевості, номери маркерів, розміри тайлів |
| `web/` | мобільний веб-застосунок (без збирання, чистий JS) |
| `tiles/` | PDF тайлів для друку, генератор PDF, перевірка фото з командного рядка |

## Запуск на комп'ютері

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

Без ключа Claude (тестовий режим, ведучий відповідає заготовками):

```powershell
$env:SNAPQUEST_FAKE_AI = "1"; .venv\Scripts\python -m uvicorn server.main:app --host 0.0.0.0 --port 8000
```

З ключем Claude:

```powershell
$env:ANTHROPIC_API_KEY = "sk-ant-..."; .venv\Scripts\python -m uvicorn server.main:app --host 0.0.0.0 --port 8000
```

Відкрий http://localhost:8000. З телефона в тій самій Wi-Fi: `http://<IP комп'ютера>:8000` —
живий видошукач камери працює лише через HTTPS, тому локально використовується кнопка
**Take photo** (відкриває звичайну камеру телефона). На хостингу з HTTPS працює і живий видошукач.

## Публікація для всіх (Render.com, безкоштовно)

1. Створи репозиторій на GitHub і завантаж туди цю папку.
2. На [render.com](https://render.com) → **New → Blueprint** → обери репозиторій
   (налаштування беруться з `render.yaml`).
3. У полі `ANTHROPIC_API_KEY` встав ключ Claude API ([console.anthropic.com](https://console.anthropic.com)).
4. Після збирання застосунок буде доступний за адресою на кшталт `https://snap-quest.onrender.com`.
   На телефоні: меню браузера → **Додати на головний екран**.

Важливо:
- Кожен хід ведучого коштує грошей з твого ключа (Claude Opus 5.5, приблизно $0.02–0.05 за хід).
  Ліміти в `render.yaml`: `SNAPQUEST_AI_PER_HOUR` на відвідувача і `SNAPQUEST_AI_PER_DAY` на весь сайт.
  Встанови також місячний ліміт витрат у консолі Anthropic.
- Безкоштовний сервер Render «засинає» без відвідувачів; перше відкриття після паузи — до хвилини.

## Тайли

`tiles/snap_quest_tiles_A4.pdf` — 50 тайлів (маркери ArUco 4x4, 12 мм) на 3 аркушах A4,
друк 100% на матовому картоні. Також доступний у застосунку: `/print-tiles.pdf`.
Перевірити фото без застосунку: `python tiles/scan_board.py photo.jpg --expect 20`.
